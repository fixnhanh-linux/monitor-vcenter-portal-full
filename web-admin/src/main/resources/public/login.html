Tạo tài khoản quản trị

Portal chưa có tài khoản nào. Tạo tài khoản admin đầu tiên để bật đăng nhập; sau đó mọi người phải đăng nhập mới xem được.

Ai mở được trang này đều tạo được tài khoản đầu tiên, nên hãy tạo ngay. Thêm tài khoản khác ở Cài đặt → Người dùng & API key.
